# 🌤️ WeatherApp — Приложение погоды на WPF

Приложение для просмотра текущей погоды и прогноза на 5 дней.

## ⚙️ Функционал

- ✅ Поиск погоды по названию города
- ✅ Отображение текущей погоды:
    - Температура (°C)
    - Погодные условия (облачно, ясно и т.д.)
    - Иконка погоды
    - Влажность (%)
    - Скорость ветра (м/с)
    - Давление (мм рт. ст.)
- ✅ Прогноз на 5 дней
- ✅ История запросов
- ✅ Сохранение настроек (последний город, тема)
- ✅ Светлая/тёмная тема

## 🛠️ Технологии

- **Платформа**: .NET 8
- **UI Framework**: WPF (Windows Presentation Foundation)
- **Язык**: C#
- **Архитектура**: MVVM
- **MVVM библиотека**: CommunityToolkit.Mvvm
- **API**: OpenWeatherMap (https://openweathermap.org/api)
- **Хранение данных**: JSON-файл (локальные настройки)
